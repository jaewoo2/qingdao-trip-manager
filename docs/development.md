# 개발 배경과 개선 과정

## 출발점

여행 중 일정, 중국어 장소명, 식당 대안을 여러 문서에서 찾는 번거로움을 줄이고 싶었습니다. 인터넷이 불안정해도 기존 일정을 볼 수 있어야 하고, 지도 서비스는 익숙한 외부 앱으로 이어지도록 구성했습니다.

개인 여행에서 출발한 프로젝트를 공개용 예시 앱으로 정리했습니다. 이 저장소에는 실제 예약·개인 여행 데이터·개인용 배포 주소와 이전 개발 저장소의 커밋을 포함하지 않습니다.

## 구현 순서

1. 고덕지도 iOS 링크 후보와 중국어 검색 대안을 구분했습니다.
2. 날짜별 일정에 메모·방문 완료·허용된 식당 교체를 추가했습니다.
3. 화면과 이미지 캐시, 저장 상태 검증, 백업·복원을 구현했습니다.
4. 여행 일정·준비물·식당 후보의 세 탭으로 나눴습니다.
5. 모바일에서 긴 식당 카드의 스크롤을 줄이기 위해 정사각형 3열 앨범과 상세 팝업을 적용했습니다.
6. 하루 전체 완료와 지난 일정별 식당 분류를 연결했습니다.

## 선택한 범위

여러 사용자의 실시간 협업보다는 한 기기에서의 저장과 복구를 우선했습니다. 지도 식별자를 임의로 채우지 않고 미확인 장소에는 검색을 제공합니다. 음식 그림은 실제 매장 사진과 구분합니다.

현재는 고정된 예시 일정과 명시적으로 연결한 식당 대안을 다룹니다. 자유로운 일정 편집은 새 장소·이벤트의 ID, 백업 호환, 완료 상태, 식당 연결 규칙을 함께 바꿔야 하므로 후속 범위로 남겼습니다.
