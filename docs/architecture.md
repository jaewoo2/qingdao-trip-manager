# 구조와 오프라인 동작

## 구성

```text
React 화면
 ├─ 일정 / 준비물 / 식당 앨범
 ├─ 예시 일정 + 계획 계층 + 기기별 변경 상태
 ├─ localStorage: 메모·체크·식당 선택
 └─ Service Worker: 화면·이미지·빌드 자산 캐시

지도 버튼 → 외부 고덕지도 서비스 / iOS 앱
```

TypeScript로 데이터와 상태를 정의하고, Vite로 정적 파일을 빌드합니다. 별도 서버·DB·로그인·LLM·지도 API Key를 사용하지 않습니다.

## 데이터와 상태

`src/data/itinerary.seed.json`은 공개용 예시입니다. `src/lib/tripPlan.ts`는 기본 식당과 허용 대안을 정의합니다. 원본 예시를 직접 변경하지 않고 `eventId → placeId` 선택, 메모, 완료 ID와 준비물 ID를 localStorage에 저장합니다.

Zod 검증으로 알 수 없는 일정·장소·허용하지 않은 대안과 손상된 백업을 거부합니다. 읽기 실패 시 원본 데이터를 덮어쓰지 않고 복구를 안내합니다. 저장 실패는 사용자에게 표시합니다.

하루 완료는 모든 이벤트의 완료 상태에서 계산합니다. 별도 날짜 완료 플래그를 두지 않아 개별 체크와 어긋나지 않습니다. 식당은 연결된 날짜의 완료 상태로 진행 중/지난 일정에 분류합니다.

## 캐시와 업데이트

Workbox `injectManifest`가 생성한 자산 목록을 Service Worker가 프리캐시합니다. 핵심 캐시와 현재 실행 스크립트가 모두 존재하는지 확인한 뒤 ‘오프라인 준비 완료’를 표시합니다. 업데이트를 사용자가 적용해도 기기별 변경 상태는 보존합니다.

캐시와 localStorage는 다른 저장소이며 둘 다 브라우저 관리 대상입니다. 홈 화면 설치만으로 영구 보관이나 Safari와 동일한 저장소를 보장하지 않습니다.

## 고덕지도 연결

중국어 검색·주소 복사를 기본으로 제공합니다. 확인된 ID 또는 GCJ-02 좌표만 iOS scheme 경로 링크 후보에 사용할 수 있습니다. HTTPS 대안은 별도 링크입니다. 출처 URL이 있다는 이유만으로 좌표·POI 검증 상태를 올리지 않습니다.

공개 예시의 모든 장소는 경로 검증 미확인 상태입니다. 연결 실험실은 사람이 확인한 식별자를 임시 입력해 시험하는 도구이며 예시 데이터의 검증 상태를 자동 변경하지 않습니다.

## 디렉터리

- `src/components`: 식당·준비물·지도·팝업
- `src/lib`: 상태 검증, 지도 링크, 일차 완료·연결 규칙
- `src/data`: 예시 일정, 준비물, 식당 정보
- `public`: 아이콘·그림·정적 자산
- `tests`: 상태/링크/컴포넌트/브라우저 검증
- `scripts`: 공개 파일 검사와 문서 화면 촬영
