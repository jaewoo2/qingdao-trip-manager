# 현재 범위와 확장 계획

## 구현됨

- 날짜별 일정·메모·완료·하루 전체 완료
- 준비물 체크와 자동 접힘
- 모바일 3열 식당 앨범, 날짜 필터와 상세 팝업
- 허용된 끼니의 식당 교체와 지도 검색 대상 변경
- 오프라인 자산 준비 확인, 로컬 저장, JSON 백업·복원

## 아직 지원하지 않음

- 식당 직접 추가 및 임의 끼니 배정
- 숙소 자유 편집
- 일정 추가·삭제·시간 변경·순서 이동
- 여행 기간 변경·여러 여행 관리
- 동행자 간 자동 동기화·서버 백업

## 다음 확장 후보

1. 사용자 장소 모델과 식당 직접 추가
2. 숙소·일정 편집과 백업 형식 버전 관리
3. 일정 추가·삭제·정렬 및 연결 규칙 검증
4. 여러 여행 지원

이는 계획이며 구현 완료 기능이 아닙니다. 현재 예시 데이터를 바꾸는 방법은 customization.md를 참고하세요.
