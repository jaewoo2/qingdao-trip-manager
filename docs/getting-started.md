# 설치와 사용 안내

## 처음 시작하기

이 앱은 브라우저에서 열어 쓰는 웹앱입니다. 홈 화면에 추가하면 앱 아이콘으로 실행할 수 있습니다. 이를 PWA라고 부릅니다. 처음에는 인터넷이 필요하며, 데이터 준비가 끝나면 일정과 변경 사항을 오프라인으로 사용할 수 있습니다.

## iPhone에 설치하기

```text
Safari에서 HTTPS 앱 열기
          ↓
공유 버튼 → 홈 화면에 추가 → 추가
          ↓
홈 화면의 앱 아이콘으로 실행
          ↓
‘오프라인 준비 완료’ 확인
          ↓
비행기 모드 → 앱 종료·재실행으로 확인
```

공유 버튼의 위치와 메뉴 표현은 iOS 버전에 따라 다를 수 있습니다. 다른 앱 안의 브라우저라면 Safari로 먼저 여세요. 로그인 화면을 사용하는 배포라면 로그인 후 실제 앱을 연 상태에서 설치합니다.

## 여행 일정

상단 날짜를 선택합니다. 방문 완료를 누르면 카드가 접히고 상세를 다시 펼칠 수 있습니다. ‘내 메모’를 열어 기록하세요. 식당의 ‘대안 보기’에서 연결된 후보로 바꾸면 음식 설명·이미지·지도 검색 대상도 함께 바뀝니다.

보라색 ‘N일차 일정 모두 완료’는 **그 날짜의 모든 이벤트**를 완료합니다. 체크를 풀면 그 날짜의 개별 완료가 전부 해제됩니다. 메모·식당 선택·준비물·음식 경험 확인은 유지됩니다. 개별 체크를 모두 눌러도 하루 완료로 인식합니다.

## 준비물과 식당

준비물은 필요한 항목을 체크하세요. 한 분류를 모두 체크하면 접히고, 제목을 누르면 다시 열립니다.

모바일 식당 탭은 3열 앨범입니다. 카드를 누르면 설명·지도·연결 끼니·일정 변경 버튼이 있는 상세 팝업이 열립니다. 날짜 필터로 볼 수 있으며, 완료된 날짜는 ‘이미 지난 일정’에 모입니다. 다른 미완료 날짜에도 연결된 식당은 진행 중 목록에도 남습니다.

## 인터넷 없이 사용하기

‘오프라인 준비 완료’를 먼저 확인하세요. 화면만 열었다고 준비 완료를 보장하지 않습니다. 준비된 기기에서는 조회·메모·후보 선택·체크를 사용할 수 있습니다. **고덕지도 검색과 경로 탐색은 인터넷을 켜고 시험**하세요.

새 버전이 보이면 ‘새 버전 적용’을 누르고 준비 완료를 다시 확인합니다. 사이트 데이터를 지우는 방식으로 업데이트하지 마세요.

## JSON 백업은 언제 쓰나요?

평소 사용에는 다운로드가 필요 없습니다. 자동 저장과 별개로 복사본을 보관하고 싶을 때 ‘백업과 여행 준비’에서 JSON을 내려받으세요. 파일에는 선택·메모·완료·준비물 상태가 들어 있습니다.

새 기기나 다른 사이트 주소로 옮길 때 복원할 수 있습니다. 복원은 현재 변경 사항을 교체하므로 안내를 확인하세요. 이 앱은 다른 사람의 변경 사항을 자동으로 합치거나 동기화하지 않습니다.

## 기록이 사라질 수 있는 경우

브라우저 저장소 삭제, 비공개 브라우징 종료, 기기 저장 공간 정리 등으로 로컬 데이터가 지워질 수 있습니다. 필요한 기록은 백업하세요. 공개 예시 앱과 개인용 앱은 저장소 이름도 구분되어 있습니다.
