# 이미지 출처와 이용 범위

## 음식 그림

프로젝트 제작자가 제공한 AI 생성 음식 일러스트 15장입니다. 실제 식당·현재 메뉴를 촬영한 사진이 아니며 그림만으로 지점·메뉴·양을 검증할 수 없습니다. 원본 참고 사진, 업로드 식별자, 생성 프롬프트는 공개본에 포함하지 않았습니다.

음식 그림은 코드의 MIT 라이선스 적용 대상에서 제외합니다. 재사용 허락은 별도로 표시하지 않았으며, 코드를 활용할 때 직접 준비한 이미지로 교체할 수 있습니다. 파일 연결은 `src/data/restaurantIllustrations.ts`에 있습니다.

## 아이콘과 화면

앱 아이콘과 해안 SVG는 프로젝트의 UI 자산이며, 음식 그림을 제외한 프로젝트 코드·문서와 함께 MIT 범위에 포함합니다. UI 아이콘 라이브러리 lucide-react와 다른 외부 의존성은 각 패키지 라이선스를 따릅니다.

`docs/screenshots/`는 공개용 예시 앱을 Chromium으로 촬영한 문서용 이미지입니다. 일정 화면의 장식 영역과 준비물의 날씨 안내는 내용 비교를 위해 촬영 시 숨겼으며, 실제 예약·기존 개인용 화면을 촬영하지 않았습니다.

식당 정보의 참고 URL은 `src/data/restaurants.ts`에 보관합니다. 외부 페이지의 실제 음식 사진이나 스크린샷은 포함하지 않습니다.
